# rotahub-web

Frontend web do RotaHub.

- **Stack:** React + Vite + Tailwind
- **MVP:** Painel do Operador como app único (microfrontends via Module Federation ficam para a fase posterior, quando o Acompanhamento do Cliente entrar)
- Consome exclusivamente o BFF (`rotahub-bff`), nunca os serviços diretamente

Mobile (React Native) fica fora deste repo — só entra depois que a web estiver pronta.
